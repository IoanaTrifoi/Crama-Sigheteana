# Crama Sigheteană

Site static pentru restaurantul Crama Sigheteană din Sighetu Marmației.

- `index.html`, `meniu.html`, `despre.html`, `contact.html`: paginile site-ului
- `style.css`, `script.js`: stiluri și interacțiuni
- `images/`: fotografii și logo
- `build.py`: generează paginile HTML (preparate, date de contact etc.). După modificări rulează:

```sh
python3 build.py
```

Site-ul poate fi publicat direct cu GitHub Pages (Settings → Pages → branch, folder `/ (root)`).
